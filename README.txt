PORTAFOLIO WEB – JUAN DAVID SILVERA

ARCHIVOS:
- index.html: página principal
- styles.css: estilos responsive
- script.js: datos de los 12 proyectos, filtros, galería, menú y formulario
- assets/: imágenes obtenidas del PDF original

CÓMO ABRIR:
1. Extrae el ZIP por completo.
2. Haz doble clic en index.html para abrir en el navegador.
3. Para publicar, sube TODO el contenido de esta carpeta a un hosting estático (Netlify, GitHub Pages, Cloudflare Pages o similar).

FUNCIONALIDADES:
- Página responsive sin dependencias externas ni necesidad de instalación.
- Galería filtrable de 12 proyectos reales con imágenes y fichas del PDF.
- Modal para ver cada proyecto, pasar al anterior o siguiente y cerrar con Escape.
- Botón WhatsApp configurado.
- Correo y sitio web enlazados.
- Formulario: prepara un correo mediante mailto; depende del cliente de correo instalado/configurado en el equipo. NO envía mensajes desde un servidor ni guarda datos.

PARA ACTIVAR ENVÍO DIRECTO DE FORMULARIO:
Integrar un servicio autorizado (Formspree, EmailJS o backend propio) y ajustar script.js.

FUENTE DE LOS PROYECTOS: PORTAFOLIO FINAL (1).pdf, 32 páginas.
La imagen de perfil, el logotipo y los diseños provienen del PDF. Los casos fueron resumidos respetando la fuente.

ACTUALIZACIÓN: Cada proyecto muestra sus dos páginas del portafolio y un botón VER MÁS que abre el enlace externo específico de Canva en una nueva pestaña.


ACTUALIZACIÓN: En VER PROYECTO se conserva la descripción; se añaden ficha técnica, relato creativo y síntesis final tomados del PDF. La página del proceso creativo se muestra únicamente como recorte del boceto. Todos los enlaces VER MÁS siguen presentes.

PARALLAX: Efecto multicapa al desplazarse por Inicio, Conóceme y tarjetas de proyectos. Desactivado en pantallas pequeñas y si el usuario solicita movimiento reducido. No requiere internet ni librerías externas.
